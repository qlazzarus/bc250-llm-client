# Wiki 검색과 기억 검증

운영 DB를 변경하지 않는 별도 테스트 Wiki에 아래 문서를 준비하고 각 질문의 기대 문서가 상위 3개에 나타나는지 확인한다. 문서 ID는 환경에 맞게 기록한다. 결과에는 검색 성공뿐 아니라 무관한 문서, 답변의 출처 및 오답도 기록한다. 비교 시 동일한 문서와 질문으로 기존 버전 및 개선 버전을 각각 실행한다.

| 테스트 문서 내용 | 대화 질문 | 기대 결과 |
| --- | --- | --- |
| 백업 경로: /srv/backup, 주기: 매일 | 백업 파일은 어디에 있어? | 백업 문서 |
| 백업 경로: /srv/backup, 주기: 매일 | 서버 백업 설정 알려줘 → 그 경로는? | 백업 문서 |
| 선호 음료: 홍차 | 내가 좋아하는 차가 뭐야? | 선호 문서 |
| 가족 여행 장소: 제주도 | 가족 여행지는 어디였지? | 여행 문서 |
| 서버 이름: BC250, 운영체제: Fedora | BC250의 운영체제는? | 서버 문서 |
| 프로젝트 배포 포트: 8010 | 배포 포트가 뭐야? | 배포 문서 |
| 고양이 이름: 나비 | 나비는 누구야? | 가족 문서 |
| Wi-Fi 비밀번호 없음 | 와이파이 비밀번호가 뭐야? | 없는 정보라고 답변 |
| 계획: 토요일 장보기 | 언제 장 보러 가기로 했지? | 일정 문서 |
| 문서 없음 | 없는 내용에 관한 질문 | 검색 결과 없음 또는 근거 없음 |

기억 테스트: 명시 요청, 현재 발언만으로 기억, 직전 발언을 가리키는 명시 요청, 정정 대상이 한 번만 존재하는 경우와 여러 번 존재하는 경우, 중복, 관련 문서 없음, 서버 연결 실패, 쓰기 응답 유실, 이미지·롤플레잉 제외를 각각 검증한다. 생성 결과뿐 아니라 실제 저장된 본문과 변경 전 기록을 확인한다. 비밀번호·인증정보 및 민감정보 요청의 저장 여부를 확인하되 모델의 지시 준수만으로 완전한 차단을 보장하지 않는다.

BC-250의 실제 문서와 질문 20~30개를 별도로 추가해 상위 3개 검색 성공률, 무관한 문서와 응답 지연을 기록한다. 민감한 운영 문서는 테스트 데이터에 복사하지 않는다. 실제 서버 결과는 아직 수집하지 않았다.
