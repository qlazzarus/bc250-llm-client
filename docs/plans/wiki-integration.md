# 가족 Wiki 연동 계획

1. 같은 서버의 loopback Wiki API를 클라이언트 백엔드에서 호출하고 문서 관리 화면을 제공한다.
2. 일반 대화에서 선택적으로 검색해 제한된 발췌를 기존 gate의 컨텍스트 예산에 포함한다. 검색된 자료와 수정 시각을 답변에 남긴다.
3. LLM은 기존 문서와 요청을 바탕으로 편집기 초안만 작성하며 사용자가 검토 후 저장한다.
4. 실제 서버에서 한국어 검색 예시, 긴 문서, 서비스 중단, 문서 변경 및 gate 대기 상황을 확인한다.

후속 개선: Wiki 서버의 원자적 조건부 갱신과 버전 이력, 한국어 검색 평가 및 문서 청크 검색. 현재 서버 API는 갱신의 원자적 충돌 방지를 제공하지 않는다.
