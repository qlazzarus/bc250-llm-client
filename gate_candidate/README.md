# Local protocol 3 gate candidate

This is an isolated, uninstalled candidate based on the admission proxy in `docs/handoff/imagegen-20261107/source.tar.gz` (`backend/app/gate.py`). It does not alter the operating gate or Studio. `create_app` takes explicit state path, upstream URL and three distinct role credentials, and an optional separate upstream API key. `provision(path)` exclusively creates a new startup-held state; never run it over existing state. A single process takes a nonblocking lock for the lifetime of the gate. The state directory and its parent must be private and controlled by the operator; the candidate does not establish filesystem ownership, service identity or network restrictions.

`/control` and `/control/identity` implement role credentials and protocol 3. Upstream responses stream to the caller and remain active until the stream closes, including on cancellation or client disconnect. Every proxied request must supply `X-Model-Epoch` from `/model-snapshot`; paused or stale requests receive 409 without being queued. `/model-snapshot` checks the gate state before and after fetching upstream `/v1/models`, returning `{ready, epoch, models}`. Its shape is a candidate contract: the Client has not yet been migrated to it. Every process start durably adds the startup hold and rotates the epoch; each new switch hold also rotates the epoch; persisted holds and any recovery reservation survive restart. Recovery reservation prevents competing Studio and switch holds, and conditional releases compare epoch and relevant holds while holding the admission lock. Writes use a durable uncertainty marker, atomic replacement and fsync; after an interrupted or uncertain write the gate refuses to start until investigated. Do not remove that marker automatically.

If forwarding has started and its outcome is unknown, or closing the upstream stream fails, the gate remains unavailable and retains the active request count instead of claiming a successful drain. On restart the startup hold remains in place until an operator verifies recovery.

This is **not ready for deployment**: migrating protocol 2 durable state requires a separately reviewed offline procedure preserving all old holds and deployment generation. Client model snapshot, all inference paths and Studio integration are not yet wired to this proxy. Loopback binding, credential provisioning, production filesystem semantics, service rollout, crash/power-loss testing and integration on the target OS remain unverified. In particular, the single-process lock and state directory must be shared across all possible instances, and the proxy must be the sole inference admission path. This candidate performs no installation or server mutation.

Run the local tests with `PYTHONPATH=. .venv/bin/pytest -q tests/test_gate_candidate_protocol3.py tests/test_worker_gate.py tests/test_worker_recovery_reservation.py`.
